PASSING WITH FLAGS 修订 1/3 · 流程步数 8 · 审核材料同步存于 review.md

怎么审（约 5 分钟）

  1. 看硬指标（校验结果）：有没有 ❌。校验位、枚举、唯一性是代码算的，不会说谎。
  2. 看语义疑点（语义抽检）：这是最需要人的部分——模型挑出「解析没错但含义可能错」的字段，你判断同不同意。
  3. 抽看对照样例（原始 vs 输出）：随手挑两条，问自己「左边这列的意思，真的是右边那个字段吗？」
  4. 扫一眼未映射清单（unmapped）：理由是否诚实，有没有本该映射却被偷懒放弃的列。

你只有三个动作：approve / reject + 意见 / abandon。你不能直接改配置文件——人一改，配置就成了「手写的」，作业的核心主张（agent 独立完成映射）就不成立了。

entity.trading_nameTrading Name["trim", "empty_to_null"]0.85Column 'Trading Name' holds values like 'Amplifon', 'Andersens Floor Coverings' and 'Access Dental Services Pty Ltd'. These are the names the businesses trade under in the discount directory, repeated across their outlets. Some carry a company suffix (e.g. 'Ali Baba Lebanese Cuisine Pty Ltd', 'ADPA Ltd'); the reviewer confirmed this is source dirt carried faithfully, so the values are left as they are. It is not mapped to entity.legal_name because the column is not labelled as a registered name and no register confirms it.
entity.trading_nameOutlet Name["trim", "empty_to_null"]0.7Column 'Outlet Name' holds outlet-level labels such as 'Amplifon Mackay', 'ADPAQ' and 'Allcracft Sewing Machines' (a typo of the trading name). Per the reviewer, the ontology allows multiple trading names, one observation each, and outlet-level names are this source's main value for downstream name matching, so it is mapped as a second entity.trading_name claim. Confidence is lower than for 'Trading Name' because some labels are location-suffixed or contain typos.
entity.websiteWebsite["trim", "empty_to_null", "url_normalize"]0.8Column 'Website' holds values like 'http://www.andersens.com.au', 'http://adpa.com.au' and 'https://andrewsairportpark.com.au'. They are the business's web address. Some are malformed at source, e.g. 'http://https://www.amplifon.com/au/'; the reviewer confirmed these double-scheme values are source dirt carried faithfully, so they are left as they are. The semantic flag on a tracking query string is likewise source content. Blank for about 8.5% of rows, which empty_to_null turns into no claim.
